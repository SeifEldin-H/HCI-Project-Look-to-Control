# Look to Control — Design Gallery

## Overview

This directory presents the initial UI design concepts for the Look to Control project.

It contains six original design assets covering the interface states, proposed interaction flow and alternative layout.

## 1. Interface States

### State 1 — Default Interface

![Default Interface](originals/state%201%20-%20default.png)

The initial dashboard displaying the available smart-home devices.

### State 2 — Device Selected

![Selected Interface](originals/state%202%20-%20selected.png)

The selected device is visually highlighted to communicate its current selection status.

### State 3 — Device Activated

![Activated Interface](originals/state%203%20-%20activated.png)

The interface illustrates the activated device state.

### State 4 — Lock Confirmation

![Lock Confirmation](originals/state%204%20-%20lock%20confirmation.png)

## 4. Design Rationale

This section will be expanded following review of the Figma designs and discussion with the designer.

Topics include:

- Device selection and activation
- Visual feedback and system status
- Confirmation of potentially risky actions
- Accessibility and alternative interaction methods
- Comparison of alternative layouts

The original design assets are preserved in the `originals/` directory. Future design revisions will be documented separately to maintain a record of the project's development.
